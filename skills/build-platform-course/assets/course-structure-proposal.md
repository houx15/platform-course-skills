规则：

- 一行对应一个 Piece。
- 先完成教学设计，再从学习路径派生 Piece。
- 每个 Piece 都必须推进方法掌握或累计学习成果；素材本身不自动占一页。
- 核心方法必须先讲解或示范，再进入引导练习、独立应用和迁移。
- 避免连续生成“看材料—答题—反思”的考试式页面。
- 交给老师前先以学生视角完整走查并修订。
- 呈现方式必须说明实际采用的 v1 block 类型，不得默认使用 text。
- 需要流程图、示意图或信息图时，只在资源栏提出建议；教师明确授权前不得生成。
- 表格确认后才生成学生课程；设计思路和教师说明不得进入 `course.json` 或 `index.md`。
